Escolas Bíblicas

Aplicativo desktop para instrutores de escolas bíblicas das Testemunhas de Jeová

Finalidade do aplicativo: o Escolas Bíblicas permite que instrutores organizem suas turmas e façam backup dos próprios dados no Google Drive, compartilhando-os com outros instrutores da mesma turma. O login com Google serve exclusivamente para identificar o instrutor e para acessar os arquivos de backup que o próprio aplicativo cria no Drive.

O Escolas Bíblicas é um aplicativo desktop (Windows e macOS) que ajuda instrutores a organizar turmas, alunos, programações, designações e avaliações — de forma 100% offline, com os dados guardados localmente no computador de cada instrutor.

O que ele faz

  • Cadastro de escolas, turmas e alunos
  • Programação de aulas, designações e reuniões modelo
  • Layout de sala e acompanhamento de avaliações
  • Backup local e, opcionalmente, compartilhado via Google Drive entre instrutores

Login com Google

Para o backup compartilhado entre instrutores, o app usa login com sua conta Google. Veja o que isso significa na Política de Privacidade.
